# One Star for Monday

Entry for the [make.fun](https://make.fun/competitions/u-clever-harbor-75-one-star-for-monday-9ead4a61)
bounty **"One Star for Monday"** (`u-clever-harbor-75-one-star-for-monday-9ead4a61`).

## The line

> One star. Monday seated me by the drafty door, served cold coffee, then billed me for the whole weekend.

19 words, 104 characters — a one-star review of Monday written as if
Monday were a restaurant: a bad table by the drafty door, a cold dish
(the coffee), and a bill that charges you for the whole weekend. Only
Monday bills you for the weekend it just took away.

## How to run

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` (Python 3, standard library only) writes the single line to
`/output/entry.txt`, creating `/output` if needed, after self-checking
the bounty gate (1–180 characters, at most 25 words, one line, plain
text).
